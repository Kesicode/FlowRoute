feat: Phase 4 - Voice Agentic Action Dispatcher & Live Copilot

services/voice-dispatcher.ts (NEW)
- Pure regex + keyword intent parser — no LLM, no network, instant offline-capable
- 9 intent categories: navigation, budget, route, map, safety, settings, trip, speak, unknown
- Number extraction happens on raw text BEFORE normalize() to preserve "1.5 lakh" decimals
- extractNumberFromRaw() supports: plain digits, "2.5 lakh" (→250000), "15 thousand" (→15000)
- Priority chain: SOS → disable safety → enable safety → route → map → budget sim →
  settings → trip → speak → navigation (nav-verb only) → short fallback → unknown
- disable safety checked BEFORE enable safety (longer phrase wins)
- Navigation only fires with explicit verb prefix (show/open/go to/switch to) OR ≤5 words
- Removes bare ambiguous keywords (trip, plan) from multiday tab to prevent false matches
- Adds hotel/hotels to accommodation tab keywords
- Hospital regex supports plural: "nearby hospitals"
- Supports EN, HI (Devanagari + romanized), ML keywords across all categories
- getIntentConfirmation(): TTS-ready response string for every intent type

hooks/useVoiceCommands.ts (NEW)
- Bridges voice-dispatcher → Zustand store actions → TTS spoken feedback
- Reads transcript from useVoice(); processes via parseVoiceIntent() in useEffect
- lastProcessedRef prevents double-processing same transcript
- Handles all 9 intent categories:
  · navigation  → setActiveTab() directly on Zustand (works from any component)
  · budget/show  → setActiveTab("budget")
  · budget/sim   → setActiveTab("whatif")
  · route        → setActiveTab("route") + CustomEvent "flowroute:set-route-mode"
  · map          → CustomEvent "flowroute:map-command" + relevant tab switch
  · safety/SOS   → setEmergencyMode(true) + setHealth("action_required")
  · safety on/off → setSafetyMode()
  · settings     → setLanguage / setCurrency / setTravelerProfile
  · trip/new     → speak + router.push("/") after 800ms
  · trip/save    → saveCurrentTrip() with full SavedTripSummary from store
  · trip/clear   → resetTrip()
  · speak/budget → dynamic TTS from remainingAmount + total allocation
  · speak/status → TTS from trip from/to
  · speak/next   → TTS from tripData.to
  · unknown      → TTS hint suggesting valid commands
