fix: Zustand infinite loop - wrap all object selectors with useShallow

Root cause: every useFlowStore((s) => ({...})) returned a new object reference
on each render, causing Zustand to see prev !== next, schedule another render,
and repeat indefinitely — manifesting as "getServerSnapshot should be cached"
and "Maximum update depth exceeded" errors in Navbar → useSettingsActions.

Fix: imported useShallow from zustand/react/shallow and wrapped all 9 object-
returning selectors in useTripStore.ts:
  useTripActions, useJourneyActions, useBudgetState, useBudgetActions,
  useSettingsActions, useUserProfile, useUIActions, useTripsListActions

Primitive selectors (string, boolean, number, null, array ref) are unchanged —
they compare by value and don't trigger the loop.
